# Contributing to mu-highly-effective

Thank you for your interest in improving this skill!

## How to Contribute

### Report Issues

Found a bug or have a suggestion? Please [open an issue](https://github.com/muippt/mu-highly-effective/issues/new/choose) and choose the appropriate template.

### Suggest Content Improvements

This skill is content-driven — the biggest value comes from:

1. New workplace scenarios for `references/workplace-scenarios.md`
2. Better diagnostic questions for `references/habit-diagnosis.md`
3. Richer check-in plans for `references/checkin-plans.md`
4. Deeper habit knowledge for `references/seven-habits-core.md`

### Submit Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b my-improvement`
3. Make your changes
4. Ensure no sensitive information is included
5. Commit with a clear message
6. Push and open a Pull Request

### Content Guidelines

- All content must be based on the 7 Habits framework
- Action items must be specific and verifiable
- Respect the book's copyright — restructure concepts, don't copy passages
- Write in plain, accessible language

### Code of Conduct

Be respectful, constructive, and kind.
