### 💡 使用示例

🔥 **"领导安排的活太多，做不完怎么办？"**
把情况用大白话贴进来，得到三段式回复——诊断（习惯3 + 习惯1）、背后的原则、明天上午就能落地的 2-3 个动作。

📊 **"帮我做个完整的习惯诊断"**
21 道自评题覆盖全部七个习惯，可以分批出题，不会像在考试。输出是一张习惯画像：进度条、105 分总分、优势项、以及被标记出来的薄弱项。

📋 **"给我一份 21 天打卡计划"**
自动挑出你得分最低的三个习惯，每个习惯排一个 7 天深耕，按"认识→觉察→工具→练习→深化→反思→总结"推进。每个任务都有做了/没做的判定标准。

✍️ **"帮我写个人使命宣言"**
五步引导：角色梳理→葬礼想象→价值观提炼→初稿撰写→决策检验。全程只提问、只反馈，绝不替你动笔。

💰 **"最近和上级关系有点紧张"**
情感账户盘点——按六大存款类型列出你近期的存款和取款行为，评估账户余额是充足还是透支，给出下周可以做的 1-2 个具体存款动作。

📅 **"天天很忙，但重要的事一件没干"**
时间矩阵整理——先脑中倾倒列全，逐项标注四象限，算出各象限比例，然后给第Ⅱ象限事务排具体时间段，并决定第Ⅲ象限哪些拒绝、哪些委派、哪些简化。

🤝 **"刚当上组长，不知道怎么带团队"**
组合场景路由。团队类问题会自动走习惯 4-5-6 主线——先修信任，再谈协作。

🔄 **"工作倦怠，完全没动力"**
习惯 7 的四层面更新规划（身体/精神/智力/社会情感），外加一次产出/产能平衡检查：看看你是不是在杀掉那只下金蛋的鹅。

### ✨ 核心亮点

#### 🚫 不做概念复读机

这条硬规则写死在 Skill 里：禁止大段复述理论、禁止拿原文引用凑数、禁止鸡汤式激励。每次回复都必须锚定你的具体处境，并且以一个"明天就能做"的动作收尾。对标的角色是陪练教练，不是讲师。

#### 📏 每个打卡任务都可验证

大多数习惯计划失败，是因为"今天要更积极主动一点"根本没法打勾。这里每个每日任务都带明确完成标准——"记录至少 3 次语言替换""产出带四象限标注的清单""记录对话过程和对方的反应"。做没做一目了然，且每个任务耗时控制在 15-30 分钟内。

#### 🎯 诊断覆盖全貌，不偏科

测评共 21 题，严格每个习惯 3 题、满分 15 分。你拿到的是完整画像，而不是只照亮你早就怀疑的那一个习惯。得分映射五档，从 ★☆☆☆☆（急需改善）到 ★★★★★（已内化），6 分及以下的薄弱项会自动被路由进打卡计划。

#### 🗺️ 12 个已映射好的职场场景

场景库覆盖：工作过载、同事抢功、方向迷茫、向上沟通不畅、总被打断、团队各自为政、工作倦怠、害怕冲突、焦虑内耗、怀才不遇、新任管理者、职业转型。每个场景都已经配好对应习惯、诊断、原则和行动。

#### ✋ 使命宣言只引导，绝不代笔

有一条显式约束禁止 Skill 替你起草使命宣言。它可以提问、可以把你的模式反射回来、可以给"这个表述很有力""这里可以更具体"这样的反馈，但字必须是你自己的。使命宣言没有标准答案，这一点被明确尊重。

#### 📈 成长连续体感知

给建议之前，Skill 会先判断你处在依赖→独立→互赖的哪个阶段。卡在依赖期的人先给习惯 1-3 和自我管理；独立期能力强但协作弱的人，会被推向"通过他人放大影响力"；已经互赖的人则聚焦习惯 7 和帮助他人成长。

#### 🧩 组合场景路由

预定义了 6 条组合路径，处理跨流程的需求——职场问题＋想打卡、诊断自然过渡到使命宣言、情感账户盘点接双赢策略等等。你不需要知道该调哪个流程。

#### 🛟 优雅降级

任何 references 文件缺失时，按既定顺序降级：先用内置的七个习惯速查表，诊断题库缺失就换成每习惯 1-10 分的简版自评，打卡模板缺失就现场生成精简版，场景库缺失就从七个习惯框架第一性原理分析。会降级，不会崩。

#### 🎙️ 教练级的对话分寸

语言规则是写明的：用"你"不用"我们"，多反问少陈述，用"你觉得呢？"把决策权还回去。打卡跟进有三档校准过的反应——完成了给具体肯定、部分完成先接纳再探索、没完成不评判只支持，连续多天没完成则温和提议调轻计划。

### 🚀 工作流

| 工作流 | 适用场景 | 触发方式 |
|---|---|---|
| 习惯诊断流程 | 评估七个习惯强弱，输出习惯画像 | "做个诊断""测测我的习惯""我哪个习惯最弱" |
| 职场疑惑解答流程 | 用七个习惯框架解析具体的职场困惑 | 任何贴进来的职场场景、冲突或困惑 |
| 打卡计划生成流程 | 生成定制化的每日练习计划 | "打卡""打卡计划""21 天""49 天""7 天计划" |
| 使命宣言引导流程 | 引导你写出自己的个人使命宣言 | "使命宣言""我到底想要什么""人生方向" |
| 情感账户盘点流程 | 分析重要关系的存款与取款收支 | "关系紧张""情感账户""信任出了问题" |
| 时间矩阵整理流程 | 事务四象限归类，制定第Ⅱ象限周计划 | "时间不够""总被打断""时间矩阵""要事第一" |

**三种交互模式**

| 模式 | 触发 | 行为 |
|---|---|---|
| 🚀 快捷模式 | 直接贴出职场场景、困惑或问题 | 读取场景库与核心知识库，识别 1-2 个主导习惯，按固定的"诊断→原则→行动"格式回复，行动粒度细到"明天就能做" |
| 💬 引导模式 | 要求做诊断／写使命宣言／定打卡计划／盘点情感账户／整理时间矩阵 | 进入上述对应的多步子流程，每个流程都有自己明确的结束条件 |
| 📋 打卡模式 | 提到打卡、7 天、21 天、49 天 | 先确认计划长度，21 天版需要诊断结果（或你自选 3 个习惯），然后输出完整计划表与打卡记录模板 |

### 🛠️ 快速开始

**1. 安装**

```bash
git clone https://github.com/muippt/mu-highly-effective.git ~/.claude/skills/mu-highly-effective
```

或者下载 Release 压缩包，解压到你的 Agent skills 目录。

**2. 确认目录结构**

```
mu-highly-effective/
├── SKILL.md
└── references/
    ├── seven-habits-core.md
    ├── habit-diagnosis.md
    ├── checkin-plans.md
    └── workplace-scenarios.md
```

**3. 直接说话就行**

```
"帮我做个七个习惯诊断"
"领导安排的活太多做不完，怎么办？"
"给我一个21天打卡计划"
```

无需配置，无需 API Key，没有初始化步骤。贴一个真实处境进去，它会自己路由到对应的工作流。

### 🔒 安全与隐私

- **零网络访问。** Skill 是纯 Markdown，不含任何脚本、HTTP 调用或埋点上报。
- **零凭证。** 不需要也不存储任何 API Key、Token、appkey 或身份认证信息。
- **数据不出本机。** 诊断分数、使命宣言草稿、关系盘点、打卡记录，只存在于你自己的 Agent 会话和你主动保存的地方。
- **无第三方服务。** 无需注册账号，无云端同步，不依赖任何外部平台。
- **内容本身较私密。** 使命宣言和情感账户盘点会触及个人价值观与真实人际关系，请把保存下来的输出当作私人笔记对待。
- **边界诚实。** Skill 被明确要求在问题超出习惯框架能解决的范围时说明自身局限并建议寻求专业帮助——它不会假装自己是心理咨询师。
- **完全可审计。** 所有行为都定义在纯文本 Markdown 里，几分钟就能从头读到尾。
